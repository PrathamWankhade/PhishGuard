# Evaluation reports

Every file in this directory is a **real artifact produced by the training /
evaluation pipeline** for the current release. No placeholder or
hand-edited numbers are committed here — if a report is missing, it has not
been generated yet and must not be cited.

| File | Produced by | What it contains |
|---|---|---|
| `evaluation_report.json` | `ai-engine/training/evaluate_model.py` | Test accuracy, per-class precision/recall/F1, confusion matrix, log loss, Brier score on the 39,148-mail stratified holdout |
| `policy_validation.json` | policy validation pass over the same holdout | End-to-end verdict rates at thresholds 75/45 (text-only), i.e. what the *product* decides, not the raw model |

Model identity, split strategy, sklearn version and dataset row counts live in
`trained_models/model_metadata.json` (gitignored artifact, regenerated by
training). The published numbers and their protocol are documented in
[docs/model_evaluation.md](../docs/model_evaluation.md).

## Regenerating

```bash
python ai-engine/training/build_final_dataset.py   # writes datasets/final/
python ai-engine/training/train_model.py           # writes trained_models/ + metadata
python ai-engine/training/evaluate_model.py        # writes reports/evaluation_report.json
```

## Not yet available

`source_split_eval.json` (group-disjoint, unseen-campaign estimate) is a
required release artifact that is **not generated yet**: it needs a dataset
build that carries the `source` column. Until it exists, the reported metrics
are random-split holdout numbers and must be described that way — do not
present them as unseen-campaign performance.
